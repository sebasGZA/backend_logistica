## 📦 Requerimientos

Instalaciones necesarias:

- Node.js (>= 18)
- npm or yarn
- Nest.js
- Git
- Docker

## 🔧 Instalacion

clonar repositorio:

```bash
git clone https://github.com/sebasGZA/backend
cd backend
npm install
```

## ⚙️ Variables de entorno

Crear un archivo .env y agrega las variables de entorno basadas .env.example

## 🐳 Docker 
Instalar docker https://docs.docker.com/engine/install
### Crear contenedor de base de datos
```bash
docker compose up -d
```

## ▶️ Correr el proyecto
```bash
npm run migration:run
npm run start:dev
``
